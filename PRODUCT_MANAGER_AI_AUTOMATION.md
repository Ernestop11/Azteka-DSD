# Product Manager AI Automation

## Overview

The Azteka DSD Product Manager now includes a complete AI-powered automation system for streamlining product ingestion, image generation, and catalog management. This system allows administrators to upload purchase orders (POs) and let AI automatically extract product data, match existing products, generate images, and create production-ready product entries.

## Features

### 1. AI Control Center

The AI Control Center is the command hub for all AI-powered automation workflows. Access it from the main Product Manager navigation under the "AI Control Center" tab (purple sparkles icon).

**Key Features:**
- Upload POs in multiple formats (PDF, CSV, Excel, Images)
- View extracted product data in real-time
- Review AI confidence scores for each extraction
- Bulk approval/rejection of AI-generated products
- Run automated image generation pipelines
- Monitor processing status with real-time updates

### 2. Automated PO Ingestion

Upload purchase orders and let AI extract product information automatically.

**Supported Formats:**
- PDF documents
- CSV spreadsheets
- Excel files (.xlsx, .xls)
- Product images (.png, .jpg, .jpeg)

**Extraction Process:**
1. Upload PO file via the AI Control Center
2. AI extracts product information:
   - Product name
   - SKU
   - Brand (AI-guessed)
   - Category (AI-guessed)
   - Price & quantity (if available)
   - AI confidence score (0-100%)
3. Review extracted items in the data table
4. Approve, reject, or retry individual items

### 3. AI Image Pipeline

Automated image processing and generation for product photos.

**Available Tools:**

#### a) Find Best Image
- Searches online databases for product images
- Uses product name and brand for accurate matching
- Returns highest quality available image
- **API:** `POST /api/auto/search-image`

#### b) Remove Background
- Automatically removes image backgrounds
- Creates clean, professional product photos
- Ideal for catalog consistency
- **API:** `POST /api/auto/bg-remove`

#### c) Enhance Image
- AI-powered image enhancement
- Improves brightness, contrast, and clarity
- Optimizes for web display
- **API:** `POST /api/auto/enhance`

#### d) Generate Promo Banner
- Creates promotional banners using Canva API
- Customizable templates
- Includes product image, price, and branding
- **API:** `POST /api/design/render-promo`

#### e) Regenerate Product Card
- Generates modern product card designs
- Multiple template options
- Combines product info with visuals
- **API:** `POST /api/design/render-product-card`

### 4. Draft Product Workflow

Products extracted or generated by AI are marked as "DRAFT" for review.

**Draft Product Indicators:**
- Yellow "Draft" badge on product cards
- Warning banner in Product Form with message:
  > "This is an AI Draft – Please Review"
  > "This product was automatically extracted or generated by AI. Please verify all information before publishing."

**Review Process:**
1. Navigate to Products tab
2. Use "AI Filters" to show "Drafts" only
3. Open draft product for editing
4. Review all extracted information:
   - Product name accuracy
   - SKU correctness
   - Category and brand assignment
   - Pricing and inventory
   - Product image quality
5. Make corrections as needed
6. Save to publish the product

### 5. AI Filters in Product List

Filter products by AI status for easier management.

**Available Filters:**
- **All Products** - Show everything
- **Drafts** - AI-generated products pending review (yellow badge)
- **AI Generated** - Products created by AI (purple badge)
- **PO Extracted** - Products extracted from POs (green badge)

**Additional Badges:**
- **Warning** (orange) - Products with AI warnings
- **Featured** (yellow) - Featured products
- **Out of Stock** (red) - Inventory status

### 6. Pipeline Status Monitoring

Real-time tracking of AI processing jobs via the AI Status Drawer.

**Status Drawer Features:**
- Overall progress bar (0-100%)
- Item counts (success/failed/remaining)
- Step-by-step pipeline status:
  - ✓ Completed (green checkmark)
  - ✗ Failed (red X)
  - ⟳ Processing (blue spinner)
  - ○ Pending (gray clock)
- Timestamps for each step
- Error and warning messages
- "Retry Failed Items" button
- Auto-refresh every 3 seconds during processing

**API:** `GET /api/auto/summary/{summaryId}`

## Complete Workflows

### Workflow 1: Upload PO → Auto-Process → Publish

**Use Case:** Quickly ingest large PO files with minimal manual work

1. **Upload PO**
   - Navigate to AI Control Center
   - Click file upload area
   - Select PO file (PDF/CSV/Excel/Image)
   - Click "Process with AI"

2. **Review Extracted Items**
   - View items in the extraction table
   - Check AI confidence scores
   - Green (≥80%) = High confidence
   - Yellow (50-80%) = Medium confidence
   - Red (<50%) = Low confidence, needs review

3. **Bulk Auto-Process**
   - Click "Auto-Process All" button
   - AI will automatically:
     - Match extracted items to existing products
     - Create new draft products for unmatched items
     - Search for product images
     - Remove backgrounds
     - Enhance image quality
     - Generate product cards
   - Status drawer opens automatically

4. **Monitor Progress**
   - Watch real-time progress in status drawer
   - Review any errors or warnings
   - Retry failed items if needed

5. **Review Drafts**
   - Go to Products tab
   - Filter by "Drafts"
   - Review AI-generated products
   - Make corrections as needed
   - Save to publish

### Workflow 2: Manual Review → Selective Approval

**Use Case:** Carefully review each item before processing

1. **Upload PO**
   - Upload file via AI Control Center
   - Wait for extraction to complete

2. **Review Each Item**
   - Check extracted product names
   - Verify SKUs match your inventory
   - Review brand/category guesses
   - Check AI confidence scores

3. **Individual Actions**
   - **Match** (refresh icon) - Re-run AI matching
   - **Approve** (checkmark) - Accept this extraction
   - **Reject** (X) - Discard this item
   - **Retry AI** (sparkles) - Re-extract with AI

4. **Approve All or Selected**
   - Use "Approve All Drafts" for batch approval
   - Or approve items individually

5. **Run Image Pipeline**
   - Click "Run Image Generation Pipeline"
   - AI processes all approved items
   - Generates images and product cards

### Workflow 3: Single Product AI Enhancement

**Use Case:** Enhance an existing product with AI tools

1. **Edit Product**
   - Navigate to Products tab
   - Click "Edit" on any product
   - Product form opens

2. **Upload/View Image**
   - If no image: Upload product photo
   - If image exists: Preview appears

3. **Use AI Image Tools**
   - Tools appear below image preview
   - Available options:
     - **Find Best Image** - AI searches for better photo
     - **Remove BG** - Removes background
     - **Enhance** - Improves image quality
     - **Promo Banner** - Creates promotional graphic
     - **Regenerate Product Card** - Creates new product card

4. **Real-Time Preview**
   - Each tool updates the image preview immediately
   - Loading spinner shows during processing
   - Toast notifications confirm success/failure

5. **Save Changes**
   - Click "Update Product" to save
   - All AI enhancements are preserved

## API Endpoints Reference

### PO Ingestion
```
POST /api/auto/ingest-po
Authorization: Bearer {token}
Content-Type: multipart/form-data
Body: { file: File }

Response: {
  items: ExtractedItem[],
  summaryId: string
}
```

### Item Actions
```
POST /api/auto/item/{itemId}/{action}
Authorization: Bearer {token}
Content-Type: application/json

Actions: match | approve | reject | retry

Response: { success: boolean }
```

### Bulk Processing
```
POST /api/auto/process-all
Authorization: Bearer {token}
Content-Type: application/json
Body: { items: string[] }

Response: {
  count: number,
  summaryId: string
}
```

### Approve All Drafts
```
POST /api/auto/approve-all
Authorization: Bearer {token}
Content-Type: application/json
Body: { items: string[] }

Response: { success: boolean }
```

### Image Pipeline
```
POST /api/auto/image-pipeline
Authorization: Bearer {token}
Content-Type: application/json
Body: { items: string[] }

Response: {
  summaryId: string
}
```

### Image Search
```
POST /api/auto/search-image
Authorization: Bearer {token}
Content-Type: application/json
Body: {
  productId: string,
  query: string
}

Response: {
  imageUrl: string
}
```

### Background Removal
```
POST /api/auto/bg-remove
Authorization: Bearer {token}
Content-Type: application/json
Body: { imageUrl: string }

Response: {
  processedUrl: string
}
```

### Image Enhancement
```
POST /api/auto/enhance
Authorization: Bearer {token}
Content-Type: application/json
Body: { imageUrl: string }

Response: {
  enhancedUrl: string
}
```

### Promo Banner Generation
```
POST /api/design/render-promo
Authorization: Bearer {token}
Content-Type: application/json
Body: {
  productId: string,
  template: string
}

Response: {
  url: string
}
```

### Product Card Generation
```
POST /api/design/render-product-card
Authorization: Bearer {token}
Content-Type: application/json
Body: {
  productId: string,
  template: string
}

Response: {
  cardUrl: string
}
```

### Pipeline Status
```
GET /api/auto/summary/{summaryId}
Authorization: Bearer {token}

Response: {
  id: string,
  status: 'pending' | 'processing' | 'completed' | 'failed' | 'partial',
  totalItems: number,
  processedItems: number,
  successfulItems: number,
  failedItems: number,
  steps: PipelineStep[],
  startedAt: string,
  completedAt: string,
  errors: string[],
  warnings: string[]
}
```

### Retry Failed Items
```
POST /api/auto/retry-failed/{summaryId}
Authorization: Bearer {token}

Response: { success: boolean }
```

## Best Practices

### For High-Quality Results

1. **PO Format**
   - Use clear, well-formatted POs
   - Include product names, SKUs, and quantities
   - Structured data (CSV/Excel) works better than unstructured (images)

2. **Image Quality**
   - Upload high-resolution product photos (min 800x800px)
   - Use well-lit, clear images
   - White or neutral backgrounds work best

3. **Review Process**
   - Always review drafts before publishing
   - Check AI confidence scores
   - Verify extracted SKUs match your system
   - Confirm brand/category assignments

4. **Batch Processing**
   - Process large POs during off-peak hours
   - Use "Auto-Process All" for similar products
   - Manual review for high-value items

### Error Handling

**Common Issues:**
- **Low AI Confidence (<50%)** - Manual review required
- **No Image Found** - Upload manually or use different search terms
- **Background Removal Failed** - Image may have complex background
- **Extraction Failed** - PO format may be unsupported

**Solutions:**
- Use "Retry AI" button for individual items
- Re-upload with better quality files
- Manually enter data for problematic items
- Check API logs in status drawer

## Performance Tips

1. **Optimize Upload Size**
   - Compress large PDF files before upload
   - Use CSV/Excel for large datasets (faster than PDF)

2. **Batch Operations**
   - Group similar products for bulk processing
   - Use filters to manage drafts efficiently

3. **Monitor Progress**
   - Keep status drawer open during large jobs
   - Retry failed items in batches

4. **Image Processing**
   - Apply background removal first, then enhance
   - Generate product cards last for final visuals

## Security Considerations

- All API endpoints require JWT authentication
- Token stored in localStorage (Bearer token)
- File uploads limited to specific types (PDF, CSV, Excel, Images)
- Maximum file size: 10MB per upload
- Image validation: PNG, JPEG only (max 5MB)

## Troubleshooting

### Upload Fails
- Check file format (PDF, CSV, XLSX, PNG, JPG)
- Verify file size (<10MB)
- Ensure valid authentication token

### No Items Extracted
- PO format may be incompatible
- Try converting to CSV/Excel
- Check for clear product data in PO

### AI Tools Not Working
- Product must be saved first (needs productId)
- Image must be uploaded/present
- Check console for API errors

### Status Drawer Not Updating
- Auto-refresh every 3 seconds
- Click "Refresh" button manually
- Check network connection
